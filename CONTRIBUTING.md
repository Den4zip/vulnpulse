# Работа с изменениями

Проект использует GitHub Flow: `main` — основная ветка, каждая новая функция или исправление разрабатывается в отдельной ветке от актуального `main`.

1. Обновите локальный `main` и создайте ветку, например `feature/project-vault` или `fix/import-cleanup`.
2. Вносите небольшие связанные изменения и коммиты. Не добавляйте секреты, рабочие базы данных, файлы проектов пользователей или результаты локальных прогонов.
3. Запустите `npm run typecheck`, `npm test -- --coverage`, `npm run build` и `npm run e2e`. Electron E2E требует рабочей графической среды и изолированных тестовых профилей; сообщайте, если проверка не выполнена.
4. Отправьте ветку в `origin` и откройте pull request в `main`. В описании укажите поведение, способ проверки и ограничения; при незавершённой работе используйте draft PR.
5. Разберите замечания и дождитесь успешных проверок CI. После готовности объедините PR через GitHub, обновите локальный `main` и удалите ветку, когда она больше не нужна.

GitHub Actions выполняет проверки для PR и основной ветки. Правила защиты ветки на стороне GitHub настраиваются отдельно; один лишь workflow не запрещает прямые изменения в `main`.
